Contributing Guide

Help us build a better social media ecosystem

Thank you for your interest in contributing to the Fix Social Media Resource List! This guide will help you get started.

Ways to Contribute

📝 Add Resources

Share tools, extensions, or resources you've found useful for improving social media quality.

🔄 Update Entries

Keep information current and accurate by updating existing resource entries.

📚 Improve Documentation

Enhance guides, fix typos, or clarify instructions in our documentation.

🐛 Report Issues

Let us know about broken links, outdated information, or other problems.

💡 Suggest Improvements

Share ideas for better organization, new categories, or enhanced features.

🧠 Expand Taxonomies

Contribute to the cognitive awareness framework by suggesting new hooks or themes.

Before You Start

  1. Search first - Check if the resource already exists in the Resources page
  2. Verify quality - Ensure the resource is legitimate, functional, and relevant
  3. Test if possible - Try the tool or extension yourself before submitting
  4. Check licensing - Prefer open-source and well-licensed resources

How to Add a Resource

Step 1: Fork and Clone

# Fork the repository on GitHub, then:
git clone https://github.com/YOUR-USERNAME/ressource-list.git
cd ressource-list
git checkout -b add-resource-name

Step 2: Add Your Resource

  1. Open RESOURCES.md
  2. Find the appropriate category (or suggest a new one)
  3. Add your resource following the existing table format
  4. Include all required information:
    • Name: The official name of the tool/resource
    • Description: A brief, clear description (1-2 sentences)
    • Platform/Browser: Supported platforms or browsers
    • Link: Official website or repository URL
    • License (if applicable): Open source license type

Step 3: Follow Formatting Guidelines

  • Use proper markdown table syntax
  • Keep descriptions concise (under 100 characters preferred)
  • Use HTTPS links when available
  • Alphabetize entries within categories when possible
  • Maintain consistent formatting with existing entries

Step 4: Commit and Push

git add RESOURCES.md
git commit -m "Add [Resource Name] to [Category]"
git push origin add-resource-name

Step 5: Create a Pull Request

  1. Go to your fork on GitHub
  2. Click "New Pull Request"
  3. Provide a clear title and description
  4. Wait for review and feedback

Resource Quality Criteria

We accept resources that meet these criteria:

  • ✅ Functional: The tool/resource is actively maintained and working
  • ✅ Relevant: Directly related to improving social media quality or digital well-being
  • ✅ Safe: No malware, tracking, or privacy concerns
  • ✅ Accessible: Free or has a free tier/version available
  • ✅ Well-documented: Has clear documentation or instructions
  • ✅ Open source preferred: Open source projects are given priority

Contributing to Taxonomies

You can also contribute to our cognitive awareness framework taxonomies:

Adding a New Hook or Theme

  1. Review the existing taxonomies in the taxonomies/ directory
  2. Identify a missing pattern or technique
  3. Add your entry following the JSON schema
  4. Provide clear descriptions and examples
  5. Include regex triggers where applicable
  6. Submit a pull request with your addition

Example Taxonomy Entry

{
  "id": "new_hook_id",
  "name": "Hook Name",
  "description": "Clear description of the attention-capture technique",
  "category": "category_name",
  "regex_triggers": [
    "^Pattern 1",
    "Pattern 2"
  ],
  "examples": [
    "Example 1",
    "Example 2"
  ],
  "severity": "low|medium|high"
}

Code of Conduct

All contributors are expected to follow our Code of Conduct. Key points:

  • Be respectful and inclusive
  • Welcome newcomers and help them learn
  • Focus on constructive feedback
  • Respect different viewpoints and experiences
  • Accept responsibility for mistakes

Review Process

After submitting a pull request:

  1. Automated Checks: Your PR will be checked for formatting and conflicts
  2. Community Review: Other contributors may provide feedback
  3. Maintainer Review: A maintainer will review and approve or request changes
  4. Merge: Once approved, your contribution will be merged

Please be patient during the review process. We're all volunteers working to make social media better!

Recognition

All contributors are recognized for their work:

  • Your GitHub profile will be listed in the repository contributors
  • Significant contributions may be highlighted in release notes
  • You'll be part of a community working to improve digital well-being

Questions or Help Needed?

If you have questions or need help:

  • 📖 Check the repository README
  • 💬 Open a GitHub Discussion
  • 🐛 Report issues in the issue tracker
