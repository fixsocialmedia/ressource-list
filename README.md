# Resource List: Fix Social Media

A collaborative, curated list of technical resources, tools, and extensions to help improve social media quality by combating AI-generated content (slop), spam, and other low-quality content.

## 📋 Table of Contents

- [About](#about)
- [Resources](#resources)
- [Contributing](#contributing)
- [License](#license)

## 🎯 About

Social media platforms are increasingly flooded with AI-generated content, spam, and low-quality material that degrades user experience. This repository serves as a collaborative hub for sharing and discovering tools, extensions, and resources that help users:

- Detect and filter AI-generated content
- Block spam and low-quality posts
- Enhance their social media experience
- Protect their privacy and security

## 📚 Resources

All resources are organized in the [RESOURCES.md](RESOURCES.md) file, categorized by:

- **AI Content Detection Tools** - Tools to identify AI-generated text, images, and videos
- **Browser Extensions** - Extensions for Chrome, Firefox, Safari, and other browsers
- **Mobile Apps & Extensions** - Solutions for iOS and Android devices
- **API & Developer Tools** - Tools for developers to integrate into their applications
- **Research & Analysis** - Academic papers, studies, and analysis tools
- **Community Resources** - Forums, communities, and discussion groups
