# Internationalization (i18n) Guide

This project supports multiple languages to make digital well-being resources accessible to users and policymakers worldwide.

## Supported Languages

Currently, the website supports:
- **English (en)** - Default language
- **French (fr)** - Français
- **Spanish (es)** - Español

## How It Works

### Translation Files

Translation strings are stored in YAML files in the `_data/translations/` directory:
- `_data/translations/en.yml` - English translations
- `_data/translations/fr.yml` - French translations
- `_data/translations/es.yml` - Spanish translations

### Language Selector

A language selector is included in the site header, allowing users to switch between available languages. The selector is implemented as a Liquid include: `_includes/language-selector.html`

### Implementation

The multilingual support uses Jekyll's built-in features:

1. **Language detection**: Pages can specify their language using the `lang` front matter variable
2. **Translation loading**: Translations are loaded from `site.data.translations[lang]`
3. **Fallback**: If no language is specified, the site defaults to English

### Usage in Templates

To use translations in your templates, access them through the translations data:

```liquid
{% assign lang = page.lang | default: site.lang | default: "en" %}
{% assign t = site.data.translations[lang] %}

<!-- Use translations -->
<h1>{{ t.home.hero_title }}</h1>
<p>{{ t.home.hero_subtitle }}</p>
```

## Adding a New Language

To add support for a new language:

1. **Create a translation file**: Copy `_data/translations/en.yml` to `_data/translations/[language-code].yml`
2. **Translate all strings**: Replace English text with translations in the target language
3. **Update the language selector**: Add the new language option to `_includes/language-selector.html`
4. **Test the translations**: Create test pages with `lang: [language-code]` in the front matter

### Translation File Structure

Translation files use a hierarchical structure:

```yaml
site:
  title: "Translated site title"
  description: "Translated description"

nav:
  home: "Translated Home"
  resources: "Translated Resources"
  
home:
  hero_title: "Translated hero title"
  hero_subtitle: "Translated subtitle"
```

## Translation Guidelines

When adding or updating translations:

1. **Be accurate**: Ensure translations convey the same meaning as the original English text
2. **Be concise**: Keep translations brief and clear, similar to the original
3. **Be contextual**: Consider cultural context and local idioms
4. **Be consistent**: Use consistent terminology throughout the site
5. **Test thoroughly**: Verify that translations render correctly in the UI

## Contributing Translations

To contribute translations:

1. Fork the repository
2. Create or update the translation file for your language
3. Test your translations locally
4. Submit a pull request with your changes
5. Include context or notes for any difficult translations

Translation contributions are highly valued and help make digital well-being resources accessible to more people worldwide!

## Testing Translations

To test translations locally:

1. Start the Jekyll development server: `bundle exec jekyll serve`
2. Open the site in your browser
3. Use the language selector to switch between languages
4. Verify that all translated text displays correctly
5. Check for layout issues or text overflow
