🚫 Ad Blocking & DNS Filtering

Block advertisements, trackers, and malicious domains at the browser or network level

🌐 Browser Ad Blockers

Browser extensions that block ads and trackers directly in your web browser. These work on a per-browser basis and give you granular control over what is blocked.

Name Description Browsers Link
🛡️ uBlock Origin Highly efficient, wide-spectrum content blocker with low memory usage. The gold standard for browser ad blocking. Firefox, Chrome, Edge, Opera GitHub | Firefox | Chrome
🦁 Brave Browser (built-in) Chromium-based browser with built-in ad and tracker blocking (Shields). No extension needed. Desktop & Mobile brave.com
🔒 Privacy Badger Automatically learns to block invisible trackers by monitoring third-party tracking behaviour. Firefox, Chrome, Edge, Opera privacybadger.org | GitHub
🍪 uBlock Origin Lite Manifest V3-compatible version of uBlock Origin for Chrome/Edge where the full version is no longer available. Chrome, Edge GitHub | Chrome
🌀 AdGuard Browser Extension Feature-rich ad blocker with a large filter library and easy allow-listing. Firefox, Chrome, Edge, Safari, Opera adguard.com

🌍 DNS-Level Ad Blocking

DNS-level blocking intercepts advertising and tracking domains before they ever reach your device. It works for all apps and devices on your network — not just the browser — making it a powerful complement to browser-based blockers.

Self-Hosted DNS Resolvers

Run your own DNS resolver on your home network or a server for maximum privacy and control.

Name Description Platform Link
🕳️ Pi-hole Network-wide ad blocker that acts as a DNS sinkhole. Runs on a Raspberry Pi or any Linux machine and blocks ads for every device on your network. Linux / Raspberry Pi pi-hole.net | GitHub
🦔 AdGuard Home Network-wide software for blocking ads and tracking. A self-hosted alternative to Pi-hole with a modern web UI and DNS-over-HTTPS/TLS support. Linux, macOS, Windows, Raspberry Pi adguard.com | GitHub
🔵 Blocky Fast and lightweight DNS proxy as an ad blocker for the local network with a focus on privacy and a simple configuration. Linux, Docker GitHub

How to Set Up a Custom DNS Resolver

You can configure a DNS resolver at different levels:

  • Router (whole network): Log in to your router admin panel and change the DNS server settings. Every device on your Wi-Fi will benefit automatically.
  • Operating System: Change DNS settings in your OS network configuration (see the Digital Well-being page for per-OS guides).
  • Browser (DoH): Modern browsers support DNS-over-HTTPS. In Firefox: Settings → General → Network Settings → Enable DNS over HTTPS.

📋 Popular Blocklists

Both Pi-hole and AdGuard Home use community-maintained blocklists. Here are widely trusted ones:

Name Description Link
StevenBlack Hosts Unified hosts file consolidating several blocklists (ads, malware, fake news, gambling, porn). Multiple variants available. GitHub
OISD Blocklist Large, frequently updated blocklist covering ads, tracking, malware, and phishing. Suitable for Pi-hole and AdGuard Home. oisd.nl
EasyList The primary filter list used by uBlock Origin and most ad blockers. Removes ads from English-language websites. easylist.to
